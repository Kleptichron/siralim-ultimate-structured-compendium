An unofficial fan project, not affiliated with Thylacine Studios. Siralim Ultimate and its effect text belong to them. Effect text and names are read from the game's own string tables; which creature or specialization each effect belongs to, and numbers like charge costs, come from community-compiled data joined onto them — verify anything load-bearing in game. The rule model, the annotations and this app are open source — source and how the tagging works.
